# Amer Saidi

**Machine Learning Engineer · Computer Vision · Signal Processing**

I work on ML for images and physical signals, from model training and evaluation to CPU inference in Python and C++. I graduated from ENSEIRB-MATMECA (Bordeaux INP) in signal and image processing. During my final-year internship at Kitware, I worked on real-time object detection with ROS 2, GStreamer and ONNX Runtime.

**Based in Paris, France. Open to ML engineering opportunities across Europe, the United States, Morocco and the Middle East.**
